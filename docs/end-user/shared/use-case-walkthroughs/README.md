# Use case walkthroughs

Narrative, end-user-facing stories showing how the pieces of Commonality fit
together for one concrete situation. These are for *persuasion and explanation* —
they're written to be read by someone deciding whether this is for them.

The complete inventory of use cases, including the many that don't have a
walkthrough yet, lives in `specs/product/use-cases.md`.
That's the status-of-record; this directory is the subset that has been written up
as prose.

## The walkthroughs

| Walkthrough | The situation | Inventory row |
| --- | --- | --- |
| [defunding.md](./defunding.md) | A town's youth mentorship program is defunded by the province; the community routes around it. | A2 |
| [local-funding-shift.md](./local-funding-shift.md) | Three towns fund shared water infrastructure without waiting on provincial grants. | A5 |
| [noninflammatory-content.md](./noninflammatory-content.md) | An ongoing pool of money for political writing that doesn't treat readers with contempt. | B2 |
| [common-sense-majority.md](./common-sense-majority.md) | People with nuanced views discover they're a majority, not a lonely exception. | C2 |
| [block-party.md](./block-party.md) | Neighbors fund a $1,500 summer block party all-or-nothing. ⚠️ Not compelling yet — secondary example only. | A1 |
| [research-funding.md](./research-funding.md) | A too-niche research project gets funded, and early backers are reimbursed once it delivers. ⚠️ Functional but the story vehicle may be wrong. | A4 |

The two marked ⚠️ carry status notes at the top of the file explaining what needs
rethinking. Don't put those front-and-center until they're revised.
