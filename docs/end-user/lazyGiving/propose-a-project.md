# Propose a project for an organization

You can start a funding project for a public identity that is not on Commonality yet — usually a website. You are the **project proposer**. You write the title and purpose. The money, if the goal is met, is reserved for whoever later proves they control that identity. You cannot take it.

This is a suggestion to the organization, not an agreement with them. It does not assign work, promise a use for the funds, or imply that they wrote the copy.

Product design: `specs/product/third-party-project-proposals-and-alignment.md`. Adoption story: [Collecting money for an org before the org is on board](../commonality/vision-and-strategy/ease-of-adoption/claiming-an-org.md).

## Two starting points

- **Propose a project** — start from an organization (a website in the MVP), then choose which causes, if any, the project fits.
- **Propose a project for this cause** — start from a statement on a cause board, then name the beneficiary.

Both use the same steps.

## What you do

1. Enter the website (or other claimable identity). The project is keyed to that canonical name, not to a display title you invent.
2. If other projects already exist for that identity, they are listed as a suggestion. Reuse one when its stated scope actually fits. You are never blocked from creating another: two projects may differ in framing, duration, or conditions.
3. If none fit, write a new title and concise purpose. Copied website text or a draft summary is only a draft; you approve the words that go on-chain.
4. Optionally attest that the project aligns with one or more statements. Each project/statement pair is its own attestation. You may skip this if you do not want to vouch.
5. Creating the project and submitting attestations are separate actions. If one step fails or you close the page, you can retry. Already-onchain attestations are not submitted again. If project creation is unclear, you will be asked to confirm which recent project is yours — the app will not create a second one for you automatically.

## What people see

Every surface keeps saying the project is **community-created; not affiliated with or endorsed by the beneficiary**, even after the organization claims the website. The proposer is shown separately from the beneficiary.

Claiming the site proves control of the name. Withdrawing funds accepts the money. Neither action rewrites who wrote the copy or counts as an endorsement of this particular project.

Alignment is always about **this project and this statement**, never “the whole organization aligns with this cause.” Organizations do more than one kind of work.

## If you are the organization

You can later [claim the website](../commonality/vision-and-strategy/ease-of-adoption/claiming-an-org.md). That does not stop other people from proposing new projects unless you separately **restrict future project creation to us**. You can reopen that later. You can also **disavow a particular project** so discovery stops promoting it. Disavowal does not cancel the contract or change escrow.
